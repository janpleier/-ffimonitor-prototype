Purpose: A web-based public transit departure board (Öffimonitor) showing nearby connections for Metalab in Vienna.
UI/Design: Built with HTML and CSS Grid, featuring color-coded routes (U-Bahn, trams) and clear countdown indicators.
Functionality: Uses a lightweight, vanilla JavaScript script to run a live clock and date, automatically formatted to local Austrian standards (de-AT).
Current State: It operates as a visual front-end mockup with static departure data, ready to be connected to a live transit API.
